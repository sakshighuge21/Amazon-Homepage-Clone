# Amazon Homepage UI Clone

A static e-commerce homepage inspired by Amazon, developed using HTML5 and CSS3.

## Project Overview
This project recreates the visual layout of an Amazon-inspired e-commerce homepage. It focuses on webpage structure, styling and layout design using basic frontend technologies.

## Technologies Used
- HTML5
- CSS3

## Features
- Navigation bar
- Search bar layout
- Product display sections
- Product images and category sections
- Footer section

## Project Structure
- `index.html` – Main webpage structure
- `style.css` – Styling and layout
- Image files – Website logos and product images

## Purpose
Created as a frontend development practice project to strengthen HTML and CSS skills.
